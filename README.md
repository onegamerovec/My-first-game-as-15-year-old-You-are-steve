# You Are Steve

My first C# text-based game.

I originally created this game when I was 15 years old, before starting high school.

## Versions

### Main
The updated version of the game.

- Bug fixes
- Czech localization
- English localization
- Japanese localization
- English and Japanese translations were created with the assistance of AI.

### Original edition with bugs
The original version of the game exactly as I created it when I was 15 years old.

It contains the original code and bugs and is preserved for historical purposes.

You can find it in the `Original-edition-with-bugs` branch.
